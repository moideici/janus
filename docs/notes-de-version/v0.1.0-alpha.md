> ⚠️ **Aperçu de recherche, pas un outil de production.**
> - Le format n'est **pas figé** : un fichier chiffré avec cette version pourrait ne plus s'ouvrir avec la suivante.
> - Le code n'a eu **aucun audit externe**, et les preuves de sécurité n'ont été **relues par personne**.
> - **Ne l'utilise pas pour de vrais secrets.**

## Ce que c'est

Janus chiffre des fichiers avec trois propriétés que gpg et age n'offrent pas ensemble :

- **Post-quantique hybride, toujours :** X-Wing, c'est-à-dire ML-KEM-768 combiné à X25519.
- **Rien à reconnaître :** chaque octet du fichier est indistinguable de l'aléa. Il n'y a ni signature d'outil, ni nombre de destinataires visible (16 emplacements toujours présents), et la taille est arrondie par PADMÉ.
- **Deux visages :** un même fichier s'ouvre sur un leurre avec un premier identifiant, et sur un secret avec un second. Personne ne peut prouver que le second existe.

`janus inspect` montre, pour comparaison, ce qu'un tiers apprend d'un fichier gpg, age, ZIP ou 7-Zip.

## Contenu

Pour chaque système, une archive contient :
- le programme `janus` ;
- la licence (MIT) et le README ;
- la liste des licences des dépendances, avec le texte Apache-2.0 de `rpassword` et `rtoolbox`.

| Système | Archive |
|---|---|
| Linux x86-64 | `janus-v0.1.0-alpha-x86_64-unknown-linux-gnu.tar.gz` |
| Windows x86-64 | `janus-v0.1.0-alpha-x86_64-pc-windows-msvc.zip` |
| macOS Apple Silicon | `janus-v0.1.0-alpha-aarch64-apple-darwin.tar.gz` |

Pour vérifier une archive, compare son empreinte avec `SHA256SUMS.txt` :

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
```

Les binaires ne sont **pas signés**. macOS et Windows afficheront donc un avertissement au premier lancement.

## Ce qui est vérifié

- **Tests :** 56 tests, qui passent sous Linux, Windows et macOS. Parmi eux, les 7 vecteurs de test publiés et le vecteur officiel d'X-Wing (draft-11).
- **Fuzzing :** 50 000 mutations de fichiers, sans aucune panique et sans jamais rendre un autre clair que l'original.
- **Temps constant :** dudect ne détecte aucune fuite sur Kemeleon, Elligator 2, la décapsulation et l'ouverture.
- **Preuves papier :** déni, intégrité, et confidentialité face aux fichiers piégés (IND-RCCA). Elles ont révélé une faiblesse face à un adversaire quantique, corrigée avant cette version.

## Limites connues

- **Pas d'IND-CCA strict :** on peut fabriquer une copie modifiée qui s'ouvre sur **le même** clair. C'est inévitable avec deux visages.
- **Un même fichier peut montrer deux contenus** à deux destinataires placés dans des visages différents. Pour vérifier qu'on a lu la même chose, il faut comparer l'empreinte du clair.
- **Un tiers peut effacer le visage caché sans que le leurre s'en aperçoive** : garde une copie.
- **L'encodage texte des clés est provisoire.**
- **Pas encore de lecture sur l'entrée standard.**
